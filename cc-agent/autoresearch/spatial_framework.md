# SPAGS 空间感知自主研究体系

## 🌟 核心框架：层次化空间感知 (Hierarchical Spatial Awareness)

```
┌─────────────────────────────────────────────────────┐
│           SPS - 空间感知系统 (场景级)                 │
│  全局-局部深度归一化 + 交叉注意力                     │
│  回答: "场景的3D结构是什么？"                         │
│  DN-Gaussian: 全局皮尔逊相关 + 逐块归一化MSE          │
│  候选增强: X-Gaussian 交叉视角注意力                   │
└──────────────────────┬──────────────────────────────┘
                       ↓ 提供几何先验
┌─────────────────────────────────────────────────────┐
│     GAR - 几何感知精化 (局部级)                       │
│  邻近引导密化 + 医学感知距离度量                      │
│  回答: "哪里需要添加/移除高斯？"                      │
│  FSGS: K近邻图构建 + 邻近阈值密化                    │
│  候选增强: 可学习邻近阈值，医学先验                    │
└──────────────────────┬──────────────────────────────┘
                       ↓ 控制高斯分布
┌─────────────────────────────────────────────────────┐
│     ADM - 自适应密度调制 (高斯级)                     │
│  三平面特征网络 + 双头MLP解码器                      │
│  回答: "每个高斯的光密度如何调节？"                   │
│  三平面位置编码 + 密度调制因子 + TV正则化             │
│  候选增强: 更高分辨率，调制与SPS/GAR联动              │
└─────────────────────────────────────────────────────┘
```

## 🔬 待探索的关键问题

### 1. SPS + GAR 互补性
- 深度先验 → 告知邻近密化哪里需要更多高斯
- **假设**: SPS深度感知能提升GAR密化的准确性

### 2. GAR + ADM 配合
- 邻近密化补充高斯 → ADM柔性地精细调制密度
- **假设**: GAR硬密化 + ADM软调制 = 最佳密度控制

### 3. SPS → GAR → ADM 流水线
- 三阶段级联：感知 → 精化 → 调制
- **假设**: 完整流水线显著优于任何单一模块

### 4. X-Gaussian 交叉视角注意力作为SPS增强
- 跨视角特征匹配 → 更好的空间理解
- **假设**: 交叉注意力能提供比深度更丰富的空间对应关系
