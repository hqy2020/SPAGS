# CoR-GS 论文调研报告：空间相关性建模分析

> **论文标题**: CoR-GS: Sparse-View 3D Gaussian Splatting via Co-Regularization  
> **作者**: Jiawei Zhang, Jiahe Li, Xiaohan Yu, Lei Huang, Lin Gu, Jin Zheng, Xiao Bai  
> **会议**: ECCV 2024  
> **代码**: https://github.com/Jiaw-Z/CoR-GS  
> **调研日期**: 2026-04-28

---

## 一、核心结论

1. **CoR-GS 的"相关性"指两个独立高斯辐射场之间的点分歧(Point Disagreement)和渲染分歧(Rendering Disagreement)，而非空间位置之间的相关性**，这与 SPAGS 的三平面特征网络有本质区别。
2. **CoR-GS 不包含显式三维空间编码模块**（无三平面特征、无哈希网格），其空间感知是通过双场协同正则化间接实现的。
3. **对 ADM 最有补充价值的是协同剪枝(Co-pruning)机制**，可直接作为后处理过滤器清除不可靠的高斯基元；伪视图协同正则化(Pseudo-view Co-regularization)可提供额外监督信号。
4. **两个方法的范式根本不同**：CoR-GS 是"训练时双场对比-剪枝"，ADM 是"空间特征编码-调制"，两者互补且可叠加。

## 二、CoR-GS 核心技术

### 2.1 核心洞察

CoR-GS 的核心发现是：**用相同稀疏视角训练两个 3DGS 辐射场，它们在训练过程中会表现出不同的行为（高斯点位置分歧和渲染结果分歧），且这些分歧与重建质量呈负相关**——分歧越大，该区域的重建质量越差。这使得无需真实数据即可无监督地定位重建不准确的区域。

分歧的根源：3DGS 的密化过程涉及从正态分布采样新高斯点的位置，这一随机性在稀疏视角下难以被优化纠正，导致两个场的分歧累积。

### 2.2 两大核心模块

#### 模块一：协同剪枝（Co-pruning）——抑制点分歧

**目的**：识别并剪除位于不准确位置的 Gaussian。

**实现流程**（对应代码 `train.py` 第 284-301 行）：

```
1. 将两个高斯辐射场 Θ¹, Θ² 视为点云
2. 对 Θ¹ 中每个高斯，在 Θ² 中找最近邻（KNN）
3. 若最近邻距离 > τ (默认 τ=5)，标记为"non-matching"
4. 剪除所有 non-matching 的高斯
5. 每隔 500 次迭代执行一次
```

**关键技术细节**：
- 使用 Open3D 的 `evaluate_registration` 计算匹配对应关系
- 距离阈值 τ 的消融实验显示：τ=5 或 τ=10 效果最好；τ=3（过严格）和 τ=30（过宽松）效果下降
- 可扩展至 2 个以上辐射场（实验显示 3-4 个场效果更好）

**与空间感知的关系**：间接的空间相关性建模——通过跨场的高斯位置匹配来识别空间中的异常点，本质上是利用"两个场在同一位置的共识度"来衡量空间位置的可靠性。

#### 模块二：伪视图协同正则化（Pseudo-view Co-regularization）——抑制渲染分歧

**目的**：在未见过的视角上约束两个场的渲染一致性。

**实现流程**：

```
1. 从训练视角中插值生成伪视角 Pose = (t + ε, q)
2. 在两个场上分别渲染伪视角图像 I'¹, I'²
3. 计算 I'¹ 与 I'² 之间的 L1 + D-SSIM 损失作为正则项
4. 总损失 = L_color (训练视图有监督) + λ_p * R_pcolor (伪视图正则化)
```

**关键技术细节**：
- `λ_p = 1.0`（正则化权重）
- 伪视角的采样频率：每隔一定迭代次数采样一次
- 深度协同正则化实验显示：颜色正则化已隐含深度约束（因渲染排序过程），额外深度正则化收效甚微

### 2.3 消融实验结论

| 配置 | LLFF PSNR | DTU PSNR |
|------|-----------|----------|
| 基线 (3DGS) | 19.22 | 17.65 |
| + Co-pruning | 19.62 | 18.59 |
| + Pseudo-view | 20.26 | 18.56 |
| **完整** | **20.45** | **19.21** |

两个模块互补：Co-pruning 主要剪除远离场景的离群高斯（使表示更紧凑），Pseudo-view 主要纠正位置接近但渲染不准确的高斯（使深度图更平滑）。

## 三、与 SPAGS ADM（三平面特征网络）的对比

### 3.1 范式层级对比

| 维度 | CoR-GS | SPAGS ADM |
|------|--------|-----------|
| **范式** | 协同正则化 (Co-Regularization) | 空间特征编码调制 (Feature Modulation) |
| **核心机制** | 双场对比 → 分歧定位 → 剪枝/约束 | 三平面编码 → MLP解码 → 密度调制 |
| **空间建模方式** | 隐式：通过跨场高斯位置一致性间接反映空间可靠性 | 显式：通过可学习特征平面直接编码三维空间 |
| **额外训练开销** | 高：训练两个完整的 3DGS 场（~2x 参数量） | 低：轻量级网络（3×32×256×256 + MLP） |
| **推理开销** | 无额外开销（只保留一个场） | 无额外开销（仅训练时使用） |
| **与基线的协同** | 可叠加在 FSGS 等深度正则化方法上 | 集成在 R²-Gaussian pipeline 中 |

### 3.2 空间相关性建模方式对比

| 方面 | CoR-GS | SPAGS ADM (三平面) |
|------|--------|---------------------|
| **"相关性"含义** | 两个独立场在相同位置的一致性 | 三维空间位置之间的结构关联 |
| **如何建模空间关系** | 跨场点云配准（KNN + 距离阈值） | 正交二维平面上的双线性插值特征 |
| **感受野** | 全局：所有高斯参与跨场匹配 | 局部：每个位置从三平面提取上下文特征 |
| **是否可学习** | 否（剪枝逻辑固定） | 是（特征平面参数可梯度更新） |
| **空间平滑性** | 无显式平滑约束 | TV 正则化约束特征平面连续性 |
| **空间异质性处理** | 通过剪除分歧高斯，间接保持几何紧凑性 | 通过偏移量+置信度的自适应调制 |

### 3.3 关键技术差异

**1. 点云级 vs 特征级**  
CoR-GS 在高斯点云层面操作（点云配准、剪枝），不涉及特征学习；ADM 在特征空间层面操作（学习三维空间的特征表示）。

**2. 离散级 vs 连续级**  
CoR-GS 的协同剪枝是离散操作（剪/不剪），在特定迭代步触发；ADM 的密度调制是连续操作（每个高斯每步都进行软调制）。

**3. 分歧定位 vs 空间先验**  
CoR-GS 定位"两个场不一致"的区域（事后检测）；ADM 提供"这个位置应该有什么样的密度"的空间先验（事前预测）。

**4. 几何约束 vs 密度优化**  
CoR-GS 主要改善高斯点的几何位置分布（让高斯更紧凑）；ADM 主要优化高斯点的密度参数（让密度更准确）。

## 四、可作为 ADM 补充的模块

### 4.1 协同剪枝（Co-pruning）— 高价值补充

**可集成性**：⭐⭐⭐⭐⭐  
**集成位置**：ADM 调制之后、周期性剪枝阶段  

**具体方案**：
1. 训练两个 SPAGS 模型（共享 ADM 网络参数或独立）
2. 在周期性剪枝步骤中，执行 Co-pruning：
   - 计算两个场的高斯点云配准
   - 标记 non-matching 的高斯（距离 > τ）
   - 剪除这些高斯
3. 保留一个场的推理结果

**预期收益**：
- 直接清除 ADM 调制后仍存在的离群高斯
- 使高斯表示更紧凑（CoR-GS 实验显示可减少 33% 高斯数量）
- 与 ADM 的软调制形成互补（软调制优化密度 + 硬剪枝清理位置）

**潜在风险**：
- 内存翻倍（需维护两个高斯场）
- 需调整剪枝阈值 τ（医学 CT 场景的单位尺度与自然场景不同）

### 4.2 伪视图协同正则化（Pseudo-view Co-regularization）— 中高价值补充

**可集成性**：⭐⭐⭐⭐  
**集成位置**：损失函数层面

**具体方案**：
1. 训练一个 SPAGS 模型，但增加额外的正则化分支
2. 从稀疏训练视角插值生成伪视角
3. 在伪视角上，利用 ADM 的特征连续性约束渲染一致性
   - 方法 A（简单版）：将同一场景不同初始化下的两次渲染结果对齐
   - 方法 B（改进版）：将伪视角渲染结果与 FDK 重建的投影对齐
4. 增加该项到总损失函数

**预期收益**：
- 提供额外的无监督监督信号，缓解稀疏视角过拟合
- 与 ADM 的 TV 正则化互补（TV 约束特征平面平滑，伪视图约束渲染一致性）

**潜在风险**：
- 需大量超参数调优（λ_p 平衡权重、伪视角采样策略）
- 在极端稀疏（3视角）下，伪视角质量可能不可靠

### 4.3 分歧感知注意力（Disagreement-aware Attention）— 概念性补充

**思路**：将 CoR-GS 的"分歧 = 不准确"思想融入 ADM 设计

**具体方案**：
1. 在 ADM 的双头 MLP 中增加第三头：预测该位置的"场间分歧分数"
2. 在训练早期，额外训练一个小型辅助场（或保留历史检查点）
3. ADM 的置信度头接收"分歧分数"作为额外输入特征
4. 在高分歧区域，ADM 自动增强调制强度；在低分歧区域，减弱调制

**优势**：将 CoR-GS 的事后检测转化为 ADM 的事前感知  
**风险**：实现复杂度高，辅助场的训练需额外管理

### 4.4 补充价值总结

| 补充模块 | 与 ADM 互补性 | 实现难度 | 预期增益 | 推荐优先级 |
|---------|:-----------:|:--------:|:--------:|:---------:|
| Co-pruning | 高（离散+连续互补） | 中 | 高 | ⭐⭐⭐⭐⭐ |
| 伪视图正则化 | 中高（约束层面互补） | 中 | 中高 | ⭐⭐⭐⭐ |
| 分歧感知注意力 | 中（概念融合） | 高 | 中 | ⭐⭐⭐ |

## 五、综合对比表

| 特性 | CoR-GS | SPAGS ADM | 能否互补 |
|------|--------|-----------|:--------:|
| 目标问题 | 稀疏视角下的高斯位置漂移 | 稀疏视角下的密度估计失准 | ✅ |
| 解决思路 | 双场分歧定位+剪枝 | 位置相关密度调制 | ✅ |
| 空间编码形式 | 无显式编码 | 三平面特征网络 | ✅ |
| 计算开销 | 2×训练 (场数) | 轻量级 (~0.1×) | ⚠️ 注意总开销 |
| 适用阶段 | 训练期周期性剪枝 | 训练期每步调制 | ✅ 可在同一流程 |
| 依赖外部数据 | 无 | 无 | ✅ |
| 推理复杂度 | 不变 | 不变 | ✅ |
| 代码成熟度 | 已开源 (PyTorch) | 已实现 (PyTorch) | ✅ |

## 六、验证建议

### 消融实验设计（3视角 CT 场景）

| 实验 | 配置 | 预期结论 |
|------|------|---------|
| 基线 | SPAGS (SPS + GAR + ADM) | — |
| +Co-pruning | ADM 输出后，执行跨场点云配准剪枝 | 高斯数量↓，PSNR↑ |
| +Pseudo-view | 损失函数增加 R_pcolor | PSNR↑，SSIM↑ |
| 完整 | ADM + Co-pruning + Pseudo-view | 最高性能 |

### 关键超参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| Co-pruning 阈值 τ | 待调（CT 场景尺度不同） | 建议从场景 bounding box 的 1% 开始 |
| Co-pruning 频率 | 每 500-1000 迭代 | 与 GAR 触发频率对齐 |
| 伪视图 λ_p | 0.5-1.0 | 从低到高扫描 |
| 伪视图采样方法 | 最近两个训练视角插值 | 与 CoR-GS 一致 |
